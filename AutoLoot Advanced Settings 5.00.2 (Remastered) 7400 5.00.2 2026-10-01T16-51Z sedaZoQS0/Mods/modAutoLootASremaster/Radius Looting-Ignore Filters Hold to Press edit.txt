How to modify the "Ignore Filters While Holding Radius Looting Key (Loots Everything)" function to activate with a single press of the Radius Looting key
(note: the function is placed at the first position in the "Radius Looting" menu)
---

1) Open "C:\Users\%USERPROFILE%\Documents\The Witcher 3\input.settings" file (optionally yet make a backup of the file before editing)

2) Find and replace all occurrences of the line below (total 9):
IK_NumPeriod=(Action=AutoLootRadiusHold,State=Duration,IdleTime=0.5)
with:
IK_NumPeriod=(Action=AutoLootRadiusHold)

3) save the file

-if you want to revert it back, just swap the lines from point 2

note: in "Radius Looting" menu, the "Ignore Filters..." function will still contain the phrase "While Holding"
